\section{研究の背景}
\label{sec:background}

近年、我が国における「予感」の重要性は高まりを見せているかもしれないし、そうでもないかもしれない。しかし、研究責任者が朝起きた瞬間に感じた「これはとてつもない予感のする研究である」という直感は、無視できないほどの重力を持って研究責任者の二度寝を妨げた。

何がとてつもないかというと、予感がとてつもないのである。具体的には、胸のざわめきが通常の「締め切り前」のそれとは異なり、「何かすごいことが起きそうだが、何が起きるかは全く不明」という点において特異である。

一方で、この経験の普遍性にもかかわらず、予感を測定する装置および尺度はこれまで報告されていない。既存の知見は飲み会の場で得られた非構造化インタビューに限られ、被験者（知人A、知人B）からは一様に「これほどとてつもない予感のする研究はこれまでに聞いたことがない」「疲れているのではないか」との回答が得られたにとどまる\cite{chijin202x}。定量的な装置についての報告は存在しない。

なお、先行研究としてNewtonはリンゴが落ちるのを見て重力を発見したが\cite{newton1687principia}、本研究における予感はリンゴが落ちるどころか、リンゴが爆発四散するレベルの衝撃を予感させるものである。

我々は、自らの主観的記録\cite{yokan202x}を出発点として、予感を物理量に変換する装置と、それを記述する新次元尺度の開発に着手した。

\section{研究の目的および意義}
\label{sec:objectives}

本研究の目的は、研究責任者が抱く「とてつもない予感」を、客観的かつ「とてつもない」指標を用いて定量することである。

具体的には、独自に開発した「とてつもない実験デバイス（TJD: Totetsumonai Jikken Device）」と、新たに定義する「とてつもない評価スケール（THS: Totetsumonai Hyouka Scale）」を用い、デバイスとの相互作用条件の違いによって予感の大きさが異なるか（リサーチクエスチョン）を記述的に検討する。

従来の研究は「仮説」に基づいて行われるが、本研究は「予感」のみに基づいて遂行される点において画期的である。論理性よりもパッションを、エビデンスよりもバイブスを重視する姿勢こそが、停滞する現代科学に物理的に風穴を開ける可能性も否定できないと考えられる\cite{dareka199x}。

本研究が完遂された暁には、(1) 学会会場がとてつもないことになる、(2)「とてつもない」という語の辞書的定義が揺らぐ、(3) 研究責任者のメンタルが鍛えられる、という社会的意義が期待される。

\section{研究対象者の選定方針}
\label{sec:subjects}

\subsection{セッティング}

\InstitutionName\ 内の研究室（TJD設置室）において、起床直後の時間帯（午前6時〜午前9時）に実施する。研究対象者の選定およびデータ取得は、すべて同室内で行う。

\subsection{適格基準}

以下の選択基準をすべて満たし、除外基準のいずれにも該当しない者を対象とする。

\subsection{選択基準}
\begin{itemize}
\item 起床直後に「とてつもない予感」を自覚した20歳以上の者
\item TJDの起動音（低い唸り声）を聞いても平静を保つことができる者
\item 本研究の説明を受け、自由意思により文書同意が得られた者
\end{itemize}

設定根拠：本研究は予感の定量を目的とするため、予感を自覚していることが測定の前提となる。また、TJDは起動時に低い唸り声を発するため、これに過度の恐怖反応を示す者では予感の強さ$P$と恐怖が分離できず、測定の妥当性が損なわれる。

\subsection{除外基準}
\begin{itemize}
\item 予感を全く抱かない者、または予感と空腹を区別できない者
\item 鋭利物との接触による外傷の既往を有する者
\item 冷や汗の分泌量が測定下限（0.1\,g）を下回ることが見込まれる者
\item 観察期間中に指導教員の呆れ具合$A$が0となることが見込まれる者
\end{itemize}

設定根拠：THSは$A$を分母に持つため（第\ref{sec:analysis}章参照）、$A = 0$ではTHSが発散し、いかなる比較も不可能となる。また、冷や汗の量$S$が測定下限を下回る場合、THSは常に0となり評価に堪えない。

\subsection{予定研究対象者数およびその設定根拠}

予定研究対象者数: 1名（研究責任者本人）、延べ20試行

設定根拠：統計学的な検出力に基づく算出は行っていない。本研究は記述的な予備的検討であり、条件間の平均THSの順序が観察できれば目的を達成できると考えられること、また現時点でTJDに自発的に接近する意思を表明した者が研究責任者以外に存在しないことから、単一被験者・20試行を予定数とした。なお本試行数は、研究責任者が1回の起床で維持可能な予感の持続時間から見込んだものである。

\section{観察・検査・調査・報告項目とスケジュール}

\subsection{測定項目、測定方法、測定者または測定機関}

すべての測定は、TJD設置室において研究責任者が実施する。外部の測定機関には委託しない。

\begin{itemize}
\item \textbf{予感の強さ $P$}：研究対象者の自己申告による11段階評価（0〜10）。「何も感じない」を0、「とてつもない」を10とする。
\item \textbf{冷や汗の量 $S$}：試行前後の実験着の重量差（g）。電子天秤を用いて測定する。
\item \textbf{指導教員の呆れ具合 $A$}：試行中の指導教員のため息の回数（回/分）。立会人が計数する。
\item \textbf{TJD出力表示値}：TJD前面の出力表示に示される値（tsu）を目視で読み取り、記録する。
\item \textbf{近隣からの苦情件数}：試行日ごとに事務局が受け付けた件数。
\end{itemize}

登録前データは利用しない。使用する記録用紙は本計画書に添付する。

\section{解析の概要}
\label{sec:analysis}

\subsection{主要評価項目}

相互作用条件別の平均THS（単位: tsu）

従来のSI単位系では本研究の「とてつもなさ」を記述できない。そこで新たな次元解析として、予感の強さ$P$、冷や汗の量$S$、指導教員の呆れ具合$A$から次式でTHSを定義する。

\begin{equation}
\mathrm{THS} = \frac{P \times S}{A^{2}}
\label{eq:ths}
\end{equation}

THSの単位は tsu（とてつもないスケールユニット）とする。

\subsection{副次的評価項目}

\begin{itemize}
\item 条件別の予感の強さ$P$、冷や汗の量$S$、指導教員の呆れ具合$A$の各平均値
\item TJD出力表示値と式\eqref{eq:ths}による計算値との一致度
\item 試行日ごとの近隣からの苦情件数
\end{itemize}

\subsection{主な解析方法}

主要評価項目については、条件ごとに試行数と平均THSを集計し、条件間の順序を比較する記述統計のみを行う。

指導教員の呆れ具合$A$の測定は本質的に不安定であり、全期間を通じて$\pm 500$\%の誤差を仮定する。この誤差の大きさに鑑み、有意差検定は実施しない。したがって本研究の結論は「順序としては一貫していた」以上のものにはならない見込みである。

副次的評価項目についても同様に記述統計のみを行う。欠測は補完せず、そのまま欠測として扱う。

なお、本研究ではゲノム解析を行わないため、個人識別符号に該当するゲノムデータの取得はない。

\section{研究対象者に生じる負担並びに予測されるリスクおよび利益・総合的評価・対策}
\label{sec:risk-benefit}

\subsection{負担・リスク}

\begin{itemize}
\item \textbf{外傷}: TJDは多数の鋭利な角を有するため、接触条件において切創・刺創のリスクがある
\item \textbf{騒音}: TJD起動時の低い唸り声により、研究対象者および近隣に不快感が生じる
\item \textbf{心理的負担}: 周囲の空気がとてつもなく重苦しくなることによる気分の低下
\item \textbf{脱水}: 冷や汗の分泌に伴う体液の喪失
\item \textbf{時間的拘束}: 1試行あたり約30分、合計約10時間
\item \textbf{対人関係上の負担}: 指導教員の呆れ具合が測定項目であるため、測定のたびに呆れられる
\end{itemize}

\subsection{利益}

研究対象者が本研究に参加することによって得られる直接の健康上の利益はない。

研究終了時に「なんかすごかった」という感慨が得られる可能性はあるが、これを保証するものではない。

\subsection{負担・リスクと利益の総合的評価}

研究対象者に直接の利益はなく、外傷および心理的負担のリスクが存在する。一方、本研究で得られる知見は、予感という広く経験されながら一度も測定されたことのない現象に、初めて数値を与えるものである。下記の対策によりリスクは許容可能な水準まで低減できると判断し、研究の実施は妥当であると考える。

\subsection{負担・リスクを最小化する対策}

\begin{itemize}
\item TJDのすべての鋭利な角に緩衝材（段ボールおよびガムテープ）を装着し、接触条件では保護手袋を着用する
\item TJD設置室の壁面に防音マットを施工し、起動時間を1試行あたり5分以内に制限する
\item 試行前後に経口補水液を用意し、自由に摂取できるようにする
\item 気分の低下を自覚した時点で、研究対象者はいつでも試行を中止できる
\item 指導教員のため息が毎分10回を超えた場合は、当該試行を直ちに中止する
\end{itemize}

\section{試料・情報の保管および廃棄の方法}
\label{sec:storage}

\subsection{試料・情報等の保管期間}

「京都大学における公正な研究活動の推進等に関する規程第7条第2項の研究データの保存、開示等について定める件」第6項に基づき、論文等の発表後少なくとも10年間保管する。

\subsection{試料・情報等の保管方法}

測定記録は施錠可能なキャビネット内のHDDに保存し、漏えい、混交、盗難、紛失等を防止する。記録用紙の原本は同キャビネット内に保管する。

TJD本体は重量物であり転倒による事故のおそれがあるため、床面に固定したうえで保管する。

\subsection{保管期間後に廃棄する場合はその処理の方法}

電子データは復元不可能な方法で消去し、記録用紙は溶解処理する。TJD本体は一般廃棄物として排出できないため、産業廃棄物として適法に処理する。

\subsection{試料・情報の提供に関する記録の作成と管理}

本研究は自機関内のみで実施し、他の研究機関との間で試料・情報の提供は行わない。したがって提供に関する記録の作成は生じない。

将来、他機関への提供を行う場合は、提供先の研究機関名、提供した情報の項目、提供年月日、提供の方法を記録し、試料・情報の保管期間と同一の期間、適切に保管する。

\section{研究対象者に係る研究結果（偶発的所見を含む）等の取扱い}
\label{sec:incidental-findings}

\subsection{説明方針の決定における考慮事項}

\begin{enumerate}
\item \textbf{精度・確実性:} 本研究で得られるTHSは$\pm 500$\%の誤差を伴い、健康状態を評価するための精度・確実性を欠く
\item \textbf{重要性:} 予感の強さは研究対象者の健康等にとって重要な事実とはいえない
\item \textbf{研究への影響:} 測定値を試行の途中で開示すると、以後の予感の申告が影響を受け、研究業務の適正な実施に支障を及ぼす
\end{enumerate}

\subsection{研究結果等の説明方針}

上記の考慮事項に基づき、\textbf{個々の測定値については研究期間中は説明しない}方針とする。全試行の終了後、研究対象者本人の希望に応じて集計結果を説明する。ただし説明者と被説明者が同一人物となるため、立会人（知人A）の同席のもとで行う。

本研究では、既存の診療情報を用いず、また臨床検査も実施しないため、研究対象者の健康等に関する重要な知見や、子孫に受け継がれ得る遺伝的特徴に関する知見が得られる可能性はない。
