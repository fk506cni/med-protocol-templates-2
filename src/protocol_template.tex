\subsection{介入研究の場合}
以下のうち、該当する事項・種類を示す:
\begin{itemize}
\item 試験の相: 探索的研究/検証的研究(相が明確な場合には第I, II, III, IV相)
\item 比較の方法: 前後比較/並行群間比較/クロスオーバー/無対照
\item 対照の種類: プラセボ対照/実薬対照/用量漸増/無治療
\item 介入の割付け方法: 割付なし/無作為化
\item 非盲検/盲検化(盲検化の場合、単盲検/二重盲検/三重盲検)
\item 評価者盲検化(介入内容の盲検化を行わない場合)
\end{itemize}

\subsection{観察研究の場合}
以下のうち、A、Bからそれぞれ該当する事項・種類を示す。B1、B2はいずれかのみ選択。

\textbf{[A: データ取得の向き]}
\begin{itemize}
\item 前向き(当該研究に用いるために研究対象者から直接取得する試料・情報を用いる)
\item 後向き(研究計画作成までに既に存在する試料・情報を取得する/当該研究とは異なる目的で研究対象者から直接取得された試料・情報の利用を含む)
\end{itemize}

\textbf{[B1: 横断的研究の場合 → 関心のある要因(曝露)とアウトカムを一時点で観察する]}
\begin{itemize}
\item 症例報告/ケースシリーズ/生態学的研究/質問紙調査/時系列分析/記述疫学的研究
\end{itemize}

\textbf{[B2: 縦断的研究の場合 → 関心のある要因(曝露)とアウトカムの観察の間に時間的経過があり、群間の比較がある]}

\section{個人情報等の取り扱い}
\label{sec:privacy}

\subsection{研究で取り扱う試料・情報等の個人情報等の種類}

\begin{itemize}
\item 個人情報: 個人を同定できる情報(氏名・診療情報等)
\item 仮名加工情報: 個人情報保護法第41条1項、個人情報保護委員会規則第31条で定める要件を満たし、作成者が、仮名加工情報としての作成意図をもって作成したもの
\item 匿名加工情報: 個人情報保護法第43条1項、個人情報保護委員会規則第34条による適切な加工を行い、特定の個人を識別することができないように個人情報を加工して得られる個人に関する情報
\item 個人関連情報: 個人情報、仮名加工情報及び匿名加工情報のいずれにも該当しないもの
\end{itemize}

\section{研究対象者に係る研究結果（偶発的所見を含む）等の取扱い}
\label{sec:incidental-findings}

研究対象者の健康、子孫に受け継がれ得る遺伝的特徴等に関する重要な知見が得られる可能性がある場合、研究対象者に係る研究結果（偶発的所見を含む）の取扱いについて、以下の事項を考慮した上で説明方針を記載する。

\subsection{説明方針の決定における考慮事項}

\begin{enumerate}
\item \textbf{精度・確実性:} 当該結果等が研究対象者の健康状態等を評価するための情報として、その精度や確実性が十分であるか
\item \textbf{重要性:} 当該結果等が研究対象者の健康等にとって重要な事実であるか
\item \textbf{研究への影響:} 当該結果等の説明が研究業務の適正な実施に著しい支障を及ぼす可能性があるか
\end{enumerate}

\subsection{研究結果等の説明方針}

本研究において研究対象者の健康等に関する重要な知見が得られる可能性について記載し、以下のいずれかの方針を選択すること。

\begin{itemize}
\item \textbf{説明する場合:} 研究結果等を説明する場合は、その方法・時期・担当者等を記載する。
\item \textbf{説明しない場合:} 説明しない場合は、その理由（上記考慮事項に基づく判断根拠）を記載する。
\item \textbf{該当しない場合:} 研究対象者の健康等に関する重要な知見が得られる可能性がない場合は、その旨を記載する。
\end{itemize}

\textbf{記載例（説明する場合）:}

本研究では、検査結果等により研究対象者の健康に関する重要な知見が得られる可能性がある。当該結果等については、研究責任者または分担研究者から研究対象者に対して説明を行う。ただし、研究対象者が説明を希望しない場合は、その意思を尊重する。

\textbf{記載例（説明しない場合）:}

本研究で得られる結果は、研究目的の解析データであり、臨床的な精度・確実性が十分に検証されていないため、研究対象者への説明は行わない。

\textbf{記載例（該当しない場合）:}

本研究では、既存の診療情報のみを用いるため、新たに研究対象者の健康等に関する重要な知見が得られる可能性はない。
